# SkyWay Embedded SDK

SkyWay Embedded SDK(以下、Embedded SDK)は、ESP32などの組み込み機器のアプリケーションからSkyWayを利用するためのSDKです。
本SDKを利用することで、組み込み機器からエンコード済みの映像・音声をリアルタイムに送信（Publish）し、任意のデータを送受信することができます。

> 💡 **NOTE**
>
> **提供状況**
> Embedded SDKは現在、β版として機能を限定して提供しています。そのため、他のSDKで利用できる機能の一部が含まれていない場合があります。また、 **API仕様が予告なく変更される可能性があります。** あらかじめご了承ください。
>
> β版の提供期間中は、SDKの品質改善および機能追加に継続して取り組んでまいります。
>
> ご利用後に気になる点がございましたら、お気軽に[お問合せフォーム](https://support.skyway.ntt.com/hc/ja/requests/new?ticket_form_id=14615614124185)よりご連絡ください。
