◆ skw_context_err_t

enum skw_context_err_t

Context APIのエラーコード。

列挙値
SKW_CONTEXT_OK 

正常終了

SKW_CONTEXT_ERR_NULL_ARGS 

引数がNULL

SKW_CONTEXT_ERR_NOT_INITED 

Contextが初期化されていない

SKW_CONTEXT_ERR_ALREADY_INITED 

Contextがすでに初期化済み

SKW_CONTEXT_ERR_DISCONNECT_FAILED 

サーバーからの切断に失敗

SKW_CONTEXT_ERR_NOT_SETUP 

Contextがセットアップされていない

SKW_CONTEXT_ERR_ALREADY_SETUP 

Contextがすでにセットアップ済み

SKW_CONTEXT_ERR_API_TIMEOUT 

Context APIがタイムアウトした

SKW_CONTEXT_ERR_MUTEX_UNLOCK_FAILED 

Context APIのアンロックに失敗

SKW_CONTEXT_ERR_APP_ID_TOO_LONG 

AppIDが長すぎる

SKW_CONTEXT_ERR_INVALID_TOKEN 

AuthTokenが不正

SKW_CONTEXT_ERR_CALLED_IN_HANDLER 

イベントハンドラ内から呼ばれた

SKW_CONTEXT_ERR_APP_ID_MISMATCH 

AuthToken内のappIdが現在のappIdと一致しない

SKW_CONTEXT_ERR_SEND_FAILED 

リクエストの送信に失敗

SKW_CONTEXT_ERR_TIMEOUT 

応答の受信がタイムアウトした

SKW_CONTEXT_ERR_CONNECTION_CLOSED 

応答待ちの間に接続が切断された

SKW_CONTEXT_ERR_RESPONSE_TOO_LARGE 

応答が受信バッファのサイズを超過した

SKW_CONTEXT_ERR_RESPONSE_PARSE_FAILED 

応答の解析に失敗した

SKW_CONTEXT_ERR_SIGNALING_NOT_ACTIVE 

シグナリングのセッションが確立していない

SKW_CONTEXT_ERR_SIGNALING_DISCONNECTED 

シグナリングが切断された（復帰はdispose後のsetup/join）

SKW_CONTEXT_ERR_SIGNALING_FAILED 

シグナリングの操作に失敗

SKW_CONTEXT_ERR_UNKNOWN 

不明なエラー

SKW_CONTEXT_ERR_BAD_REQUEST 

不正なリクエスト

SKW_CONTEXT_ERR_UNAUTHORIZED 

AuthTokenが不正、もしくは有効期限切れ

SKW_CONTEXT_ERR_FORBIDDEN 

必要な権限が無い

SKW_CONTEXT_ERR_NOT_FOUND 

リソースが見つからない

SKW_CONTEXT_ERR_ALREADY_EXIST 

すでに存在するリソースを作成しようとした

SKW_CONTEXT_ERR_TOO_LARGE 

リクエストが大きすぎる

SKW_CONTEXT_ERR_TOO_MANY_REQUESTS 

レートリミット超過

SKW_CONTEXT_ERR_SERVER_INTERNAL 

サーバー内部エラー

SKW_CONTEXT_ERR_SERVER_BUSY 

サーバーが過負荷で一時的に利用できない

SKW_CONTEXT_FATAL_ALLOCATE_FAILED 

致命的エラー: メモリ確保に失敗

SKW_CONTEXT_FATAL_CLEANUP_FAILED 

致命的エラー: クリーンアップに失敗

SKW_CONTEXT_FATAL_SETUP_FAILED 

致命的エラー: セットアップに失敗

SKW_CONTEXT_FATAL_CONNECT_FAILED 

致命的エラー: サーバーへの接続に失敗

SKW_CONTEXT_FATAL_INIT_FAILED 

致命的エラー: 初期化に失敗
